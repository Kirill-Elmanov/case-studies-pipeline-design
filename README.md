# Кейс: Переустройство магистрального газопровода при строительстве автодороги

## Задача
Вынос участка МГ Ø1220 мм, L=450 м из зоны строительства федеральной трассы в условиях сжатых сроков и невозможности остановки транспорта газа.

## Ограничения
- Запрет на остановку перекачки (действующий МГ)
- Грунты 2 категории по сейсмичности
- Срок: 4 месяца от ПД до начала строительства

## Решение
1. Применён метод ГНБ (горизонтально-направленное бурение) для прокладки нового участка
2. Врезка выполнена безогневым методом с применением системы "STOPLE"
3. Расчёты прочности выполнены по методике Газпром ВНИИГАЗ с запасом 1,2

## Результат
- Проект согласован с Заказчиком за 2,5 месяца (цель: 4 мес.)
- Получено положительное заключение ведомственной экспертизы без критических замечаний
- Строительство выполнено в срок, без остановки транспорта газа

## Технологии
AutoCAD, Model Studio CS, расчёты в Mathcad, координация через TDMS
