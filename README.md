# Кейс: Переустройство магистрального газопровода при строительстве автодороги

## Задача
Вынос участка МГ Ø1420 мм, L=1450 м из зоны строительства федеральной трассы в условиях сжатых сроков и невозможности остановки транспорта газа.

## Ограничения
- Запрет на остановку перекачки (действующий МГ)
- Обводненные грунты 2 категории по сложности разработки
- Срок: 4 месяца от ПД до начала строительства

## Решение
1. Применён метод ГНБ (горизонтально-направленное бурение) для прокладки нового участка
2. Врезка выполнена безогневым методом с применением системы "STOPLE"
3. Выполнена замена грунта на участке перехода под автомобильной дорогой
4. С целью оптимизации земляных работ были разработаны и примененены типы прокладки, что позволило сократить срок разработки документации на 5%
5. Написаны программы и макросы, для автоматизации расчетов
6. Проведен расчет и выбор балластирующих устройств
7. Заложена свеча с устройством отбора газа
8. ПД выполнена в соответствии с СП 341.1325800.2017, СП 36.13330.2012, СП 86.13330.2022, СП 45.13330.2017 и СТУ, разработанных Заказчиком

## Результат
- Проект согласован с Заказчиком за 2,5 месяца (цель: 4 мес.)
- Получено положительное заключение ведомственной экспертизы без критических замечаний
- Строительство выполнено в срок, без остановки транспорта газа

## Технологии
AutoCAD, расчёты в Excel, Visual Studio, координация через TDMS
